# NYC Film Permits：主要发现

1. **时间比较必须对齐窗口**：2025 年完整年度 5,491 条，相比 2024 年变化 -12.5%；2026 年上半年 2,615 条，相比 2025 年同期变化 +7.0%。2026 年全年不可比较。
2. **电视相关记录最多**：Television 7,959 条，占 41.0%；许可活动中拍摄许可占 78.0%。这些都是许可记录，不是作品数。
3. **首个行政区分布集中、类别组合不同**：Manhattan 与 Brooklyn 合计占 83.7%；Manhattan 内 Theater 占 27.9%，Brooklyn 内 Television 占 40.8%。
4. **开始安排偏向工作日，计划跨度存在长尾**：工作日平均 18.02 条/日，周末 7.09 条/日；有效跨度中位数 15.0 小时，均值 22.2 小时。
5. **可观测提交提前量通常为数天**：中位数 5.54 天，但此项只覆盖 17,015 条完整案例，不能视作审批用时。

**数据限制**：本地快照无法保证涵盖全部许可，更不涵盖不需许可的制作。时间覆盖完整年度不等于记录完整；日期缺失会使时间分析低于全体构成的样本数。8 条错位行隔离，17 条负跨度与异常录入日期需进一步核实。Borough 只是首个行政区；多值编码不拆分为独立许可；缺少作品唯一 ID、收入、实际执行状态、审批日期和外部事件变量。因此分析是描述性比较，不支持因果、收入、作品数量或效率推断。
