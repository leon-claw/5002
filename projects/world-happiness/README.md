# World Happiness

排名背后的差异有多确定？固定国家样本后，跨年变化还成立吗？

## 复现

从仓库根目录运行 `python3 projects/world-happiness/eda.py`，再运行 `python3 scripts/build_sites.py`。依赖见根目录 requirements.txt。

## 分析过程

1. 直接从原始 xlsx 读取，验证国家 × Year 唯一；保留三年平均语义。
2. 按真实年份索引；2013 缺失不补假点。
3. 计算全年份平衡国家面板，与当年全样本等权均值对比。
4. 比较共同国家的起止分数；原表区间用于表达排名不确定性。
5. 审计贡献项之和与总分的构造关系，不训练循环预测模型。
6. 逐年逐字段覆盖审计，并比较国家间和国家内关联。

## 实际计算的结论

### 排名接近时，先看区间

最新数据 Year=2025，147 国。带区间的相邻排名共 146 对，其中 143 对区间重叠。重叠不是正式差异检验，但说明单凭名次难以支持精确优劣判断。

### 跨年比较必须固定国家集合

所有 14 个可用年份都存在的国家有 129 个。可切换“当年样本均值”和“固定国家均值”检查覆盖变化。2011 与 2025 共同出现的 141 国中，Serbia 的分数增加最多（+2.127），Afghanistan 下降最多（-2.812）；均是三年平均评价的差。

### 解释项与总分存在构造关系

完整分解的 1,013 行中，六项贡献加 residual 与总分的最大绝对差为 0.0030（舍入及源数据差异）。用这些贡献项预测总分会有构造性循环，不能把高拟合度当研究发现；页面把分解用作描述。

### 早期缺失是整批字段缺失

2019 年以前的 lower/upper 和分解贡献在当前文件中整批缺失；2013 年没有记录。保留真实年份间隔，不能把缺失值填 0 或连成不存在的年度观测。

## 局限

- 国家等权均值不是世界人口平均；国家命名差异按原表精确匹配，未猜测合并。
- 连续 Year 的三年平均窗口可能重叠，变化不等于独立年度冲击。
- 分解贡献是模型输出，不是原始宏观变量或清晰因果效应。
- 区间重叠仅作可视诊断，不替代两国差值的正式统计检验。

## 可审计产物

`eda_profile.csv` 是原始字段统计，`analysis/` 保存全量分析汇总；页面抽样不用于计算结论。`site/data.js` 保存可视化数据。原始文件的 SHA-256 记录在页面的数据来源区域。
