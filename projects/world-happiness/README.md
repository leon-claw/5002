# World Happiness Report · EDA + D3

## 研究问题

幸福评价在不同国家和年份之间如何变化？排名差距有多大，GDP、社会支持、健康和自由等解释维度如何构成最新一期的分数？

## EDA 流程

1. 将原始 xlsx 转为 `data/processed/world-happiness/world_happiness.csv`，避免运行时依赖 Excel 引擎。
2. 重命名字段，检查年份、国家基数、缺失率和重复行。
3. 提取最新年份的头尾排名、头部国家时间轨迹、whisker 区间和解释变量构成。
4. 页面所有年份值都标注为 life evaluation 的三年平均。

## 关键限制

- 排名相近的国家可能在不确定区间上重叠，不应把名次差异写成确定性差异。
- 解释变量是报告的分解维度，不等于因果模型的回归系数。
- 国家覆盖随年份变化，跨年比较前要先检查样本覆盖。
