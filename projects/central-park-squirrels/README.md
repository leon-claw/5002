# Central Park Squirrel Census · EDA + D3

## 研究问题

中央公园的松鼠观察是否存在空间热点、班次差异和行为组合？这是 citizen-science 数据，适合做一个有地图叙事的真实城市项目。

## EDA 流程

1. 解析数字日期 `MMDDYYYY`，将 X/Y 作为空间坐标。
2. 将行为字段统一为布尔值，计算总体与班次行为率。
3. 统计颜色、班次、日期、空间网格和抽样点。
4. 缺失颜色和叙述字段保留为 `Unknown`，不凭空填补。

## 关键限制

- 这是一次 2018 年普查，不是连续追踪；空间点不是移动轨迹。
- 观察者、天气和路线选择可能造成抽样偏差。
- 页面展示的是观察频率，不等同于整个中央公园松鼠群体的真实比例。
