从数据中得到的发现

统计量来自全量 Python 分析；以下文字已写入 HTML。

FINDING 01

行为组合比单一排名更有信息

在 3,023 条观测里，所选行为中绝对值最大的非对角 φ 相关为 Runs from 与 Indifferent：φ=-0.467。这些布尔行为允许同时出现，不能画成互斥类别饼图。

FINDING 02

把 AM/PM 差异放回同一空间比较

同时出现 AM 与 PM 观测且所选行为完整的 274 个 hectare 内，等权平均的 Foraging 差值（PM−AM）为 +6.5 个百分点；按 hectare 重采样 1,000 次的探索性 95% 区间为 [+0.3, +12.2]。

FINDING 03

空间热点首先是“观察热点”

普查覆盖 11 个日期、339 个 hectare。地图保持经纬度局部比例，支持缩放、班次和毛色筛选。没有记录搜索时间和漏检率，因此点密度不等于松鼠真实密度。

FINDING 04

观察 ID 并非完全唯一

有 5 条超额重复 ID 记录，坐标不同，不能直接判定为重复观测。主分析保留全部记录；按 ID 仅保留首条后的敏感性检查中，所选行为率最大变化为 0.059 个百分点。

可复现的分析过程

  1. 原始 31 字段与观察 ID 重复审计；日期按 MMDDYYYY 解析。
  2. 行为转换为 nullable boolean，缺失不当作 False。
  3. 计算非互斥行为的 φ 共现矩阵和 AM/PM Wilson 区间。
  4. 只在共同 hectare 内比较 AM/PM，hectare 等权；固定随机种子做 1,000 次块级 bootstrap。
  5. 地图基于全部原始点，按局部距离比例投影；不伪造移动轨迹或调查边界。

结论的适用边界

  • 一次观察普查，不是追踪个体；观察 ID 不能保证松鼠生物个体独立。
  • hectare 控制只消除部分空间构成差异，天气、日期、观察者与搜索时长仍未知。
  • 区间是探索性不确定性表达，不修正便利抽样和多重比较。
  • 地图无外部底图，显示实际坐标与比例尺，不代表测量了公园边界。
