# NASA Exoplanets · EDA + D3

## 研究问题

我们看到的系外行星样本，究竟是由发现方法塑造的，还是由真实物理分布塑造的？页面把 discovery method、发布状态、发现年份、天球坐标和少量物理量放在同一条叙事线上。

## EDA 流程

1. 读取 NASA Planetary Systems CSV，保留 355 个字段的字段级 profile。
2. 把 `soltype` 归并为 `Confirmed`、`Candidate`、`Other`，不把候选星体静默当成已确认行星。
3. 解析发现年份、RA/DEC、轨道周期、平衡温度、半径和恒星温度。
4. 计算年份×状态、发现方法、设施、天球散点和物理量散点；D3 只接收抽样/聚合数据。

## 关键发现与限制

- Transit 占绝大多数记录，方法分布会强烈影响样本。
- 高缺失主要是结构性缺失：不同测量方法并不提供相同的物理字段。
- 这不是适合直接做“宜居性结论”的完整测量表；页面将缺失和候选状态显式放大。

运行 `python3 eda.py` 重新生成所有输出，打开 `index.html` 查看页面。
